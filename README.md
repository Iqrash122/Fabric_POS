# Fabric POS

Laravel + React/TypeScript/Inertia application for fabric retail and inventory management.

## Core workflow

Vendor → Purchase Bill → Goods Receipt → Individual Fabric Rolls / Barcodes → Inventory → POS Sale → Customer Payment / Credit → Returns / Refunds → Cash / Bank → Reports.

## Included modules

- Fabric products, categories, colors and exact-roll inventory
- Vendors, purchase bills and partial goods receiving
- POS sales, barcode lookup and thermal/A4 invoices
- Customer balances, advances, collections and statements
- Vendor balances, advances, installments and statements
- Customer returns/refunds and vendor returns/refunds
- Cash/bank accounts, transfers and expenses
- Reservations, physical stock counts and stock adjustments
- Promotions and marketing contacts/campaign records
- Reports with CSV/XLSX export
- Owner, manager and cashier access
- Audit history

This build is Fabric-only. Stitching orders, measurements, tailoring workflow and stitching documents are not part of this application.

Responsive UI hardening applied for desktop zoom, tablet and mobile breakpoints.
